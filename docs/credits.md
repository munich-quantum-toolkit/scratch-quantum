# Credits

The editor is built on Scratch 3.0, developed by the [Scratch Foundation](https://scratch.mit.edu).
It uses the open-source `scratch-vm` and `scratch-gui` repositories, which you can find on [GitHub](https://github.com/scratchfoundation).

The quantum extension, its simulators, the resource estimation, and the MLIR export are developed by the Chair for Design Automation, Technical University of Munich.

The blocks in these pages are drawn with [scratchblocks](https://github.com/scratchblocks/scratchblocks).
