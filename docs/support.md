# Support

If you found a bug or want to suggest a feature, please open an issue in the [issue tracker](https://github.com/munich-quantum-toolkit/scratch-quantum/issues).
To help us reproduce a problem, include the following:

- the browser and its version,
- the steps that lead to the problem, and
- if possible, the project as an `.sb3` file.

If you have questions about the Munich Quantum Toolkit (MQT) in general, have a look at the [MQT documentation](https://mqt.readthedocs.io).
